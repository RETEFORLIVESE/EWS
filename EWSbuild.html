⬆ Pubblica su EWS

Le pagine scelte vengono scritte direttamente nella repo GitHub del sito EWS (un commit per pagina). Il sito si aggiorna da solo dopo circa un minuto. Ogni versione precedente resta recuperabile dalla cronologia dei commit.

Come ottengo il token?

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. Scegli «Only select repositories» e seleziona solo la repo del sito. In Permissions imposta Contents: Read and write. Copia il token qui sopra: non viene mai inviato a nessun altro sito oltre a GitHub.
